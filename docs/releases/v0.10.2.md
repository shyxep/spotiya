Spotiya 0.10.2 — сборка форка [shyxep/spotiya](https://github.com/shyxep/spotiya) на основе оригинального 0.10.1. Soloist работает на Яндекс Станции Мини 1 (YNDX-0004): звук, громкость, много треков подряд без остановок, без щелчка при старте. На Мини 2 и других колонках поведение не меняется.

### Изменения

- Пакет совместимости Soloist содержит каталог `mini1/`, который используется только при профиле `mini1`: `libglib` и `libpcre` для apulse, прокладка `libldexp.so` и настройки в `run.sh`. Soloist больше не падает с `Pipewire initialization failed` / `playback_error_audio_driver`.
- Прокладка подставляет `__ldexp` и `__frexp`, вызывает нужную версию `snd_pcm_hw_params_set_rate_near` и заполняет тишиной кадры, которые модуль `samplerate` оставляет незаполненными (щелчок при первом запуске музыки).
- `run.sh` для Мини 1: вывод через `dmixer_auto`, громкость убавляет apulse, дампы ядра `syscall 403` отключены.
- apulse: `pa_stream_flush` сбрасывает кольцевой буфер (хвост прежнего трека при переключении), `read_index` не учитывает досыпанную тишину (остановка после конца трека).
- Громкость Soloist синхронизируется с Алисой (Glagol `setVolume`); отключается `SPOTIYA_ALICE_VOLUME=0`. Кеш Soloist держится не больше 20 МБ.
- Обновления и установщик берутся из релизов этого форка.

Подробное описание причин: [klockky/spotiya#13](https://github.com/klockky/spotiya/issues/13).

### Установка

Пошаговая инструкция для Мини 1, в том числе если уже стоит оригинальный spotiya: [soloist/README.md](https://github.com/shyxep/spotiya/blob/main/soloist/README.md#установка-на-мини-1).

Если spotiya из этого форка уже стоит:

```sh
spotiya update
spotiya addon install soloist
spotiya restart
```

На Мини 1 на `/data` около 89 МБ; если при установке Soloist не хватает места, сначала `spotiya addon remove soloist`.

### Проверка

CI: `cargo fmt`, `clippy -D warnings`, 131 тест, `shellcheck`, сборка пакетов ARMv7 (glibc 2.23). На колонке Мини 1 с Soloist 1.3.10.82 проверены на слух: запуск и звук, громкость с телефона, переключение треков, стыки между песнями, отсутствие щелчка. На Мини 2 эти изменения не проверялись.
